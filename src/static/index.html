2. Available Causal Analysis Methods

Six estimators designed for experimental and observational causal inference with explicit identification assumptions.

Method 1

Unadjusted ATE

Computes the raw difference in group means between treated and control units, accompanied by Welch's robust standard errors and confidence intervals.

Assumption: Randomized treatment assignment
POST /api/causal/unadjusted-ate
Method 2

Regression-Adjusted ATE

Adjusts for observed confounders using G-computation (standardization) over an Ordinary Least Squares outcome response surface.

Assumption: Conditional unconfoundedness, correct outcome model
POST /api/causal/regression-adjusted-ate
Method 3

Propensity Scores

Estimates conditional probabilities of treatment assignment via logistic regression, producing overlap diagnostics and common support tests.

Assumption: Positivity (0 < e(X) < 1), no unmeasured confounders
POST /api/causal/propensity-scores
Method 4

IPTW ATE

Reweights observations by inverse propensity scores using the Hájek estimator. Reports Kish effective sample size and covariate balance (SMD).

Assumption: Strong exchangeability, positivity
POST /api/causal/iptw-ate
Method 5

Difference-in-Differences

Computes double-differenced treatment effects across two groups and two time periods, removing time-invariant unobserved confounding.

Assumption: Parallel counterfactual trends
POST /api/causal/difference-in-differences
Method 6

Sensitivity Analysis

Quantifies the vulnerability of causal estimates to unmeasured confounding bias and tests weight stability under propensity score truncation.

Assumption: Bounded unmeasured confounding bias
POST /api/causal/sensitivity-analysis
